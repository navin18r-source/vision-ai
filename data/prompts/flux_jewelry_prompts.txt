- Steps: 25-30 for best quality

FOR FLUX SCHNELL (FASTER):
- Good for quick iterations
- Use same prompts, quality slightly lower but still usable

TIPS FOR BEST RESULTS:
1. Copy prompt exactly as written
2. If result isn't perfect, regenerate 2-3 times
3. Save highest quality version
4. Maintain consistent naming convention

FILE NAMING CONVENTION:
- RING_001.png, RING_002.png, etc.
- NECKLACE_001.png, NECKLACE_002.png, etc.
- Keep original high-quality for ground truth
- Create degraded versions in separate folder
